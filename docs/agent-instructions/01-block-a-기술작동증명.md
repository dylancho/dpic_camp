# 블록 A — 기술 작동 증명 (게이트: 1개 이상 충족 필요)

이 문서는 세 블록 중 **(A) 기술 작동 증명**만 다룬다. 다른 블록(B: 해자, C: Scale-up
준비)은 이 문서에 없다 — 섞어서 조사하지 마라. 이 문서를 사용할 때는 반드시
`00-evidence-schema.md`도 함께 읽는다. 출력 형식·상태 판정·출처 등급은 그 문서가 정의한다.

대상 기업과 적용 아키타입(산업 유형)은 사용자가 프롬프트에 알려준다. 아키타입이
주어지지 않았다면 아래 "판정 기준" 원문(중립 기준)을 그대로 쓰고, 산업 특성에 맞게
임의로 완화하거나 강화하지 마라.

## 하지 않는 일 (다시 강조)

- **점수를 세지 마라.** 몇 개 항목이 충족됐는지 계산하지 마라
- **게이트 통과 여부를 판정하지 마라.** "1개 이상 충족"이라는 게이트 조건이 있다는
  것만 참고 정보로 알아두고, 통과했는지 결론 내지 마라 — 그건 코드가 한다
- **근거 없이 추정하지 마라.** 못 찾았으면 `UNVERIFIABLE`이 정답이다

## A1 — PoC 재현성 (`A1_poc_reproducibility`)

**판정 기준 (원칙 원문)**: 서로 다른 고객·환경에서 PoC 2회 이상, 핵심 성능 KPI가
±10~20% 내 재현

**아키타입별 치환**:

| 아키타입 | 대체 기준 |
|---|---|
| `deep_tech` | (원문 그대로) |
| `materials` | Pilot run 2회 이상 + 고객 qualification 1건 이상, 재현성 ±10~20% |
| `industrial_hardware` | (원문 그대로) |
| `energy_infra` | (원문 그대로) |
| `recycling` | 파일럿 recovery rate 검증 2회 이상 |
| `software_ai_robotics` | 서로 다른 환경에 배포 2건 이상, 핵심 성능 재현 |

**어디서 찾는지**: 회사 IR 자료·기술 소개서의 PoC/파일럿 이력, 고객사 보도자료나
공동 발표, 학회·컨퍼런스 발표 자료, (상장 준비 중이면) 증권신고서·투자설명서의
사업 현황 서술.

**무엇을 인용할지**: PoC/파일럿을 수행한 고객·현장의 수, 각 회차의 핵심 성능 KPI
수치와 그 재현 폭. "여러 고객사와 PoC를 진행했다"처럼 건수가 불명확한 서술은
근거로 충분하지 않다 — 건수와 수치가 명시된 문장을 인용하라.

## A2 — 제3자 검증 (`A2_third_party_validation`)

**판정 기준 (원칙 원문)**: 제3자 시험성적서 또는 독립 인증 2건 이상
(Founder 자체 테스트만 있으면 불인정)

**아키타입별 치환**:

| 아키타입 | 대체 기준 |
|---|---|
| `deep_tech` | 제3자 검증 2건 이상 (장기 validation 허용) |
| `materials` | (원문 그대로) |
| `industrial_hardware` | (원문 그대로) |
| `energy_infra` | (원문 그대로) |
| `recycling` | (원문 그대로) |
| `software_ai_robotics` | (원문 그대로) |

**어디서 찾는지**: 공인시험기관(KTL, KTC, 각종 국가공인시험소 등) 시험성적서,
국제/국내 인증기관(UL, CE, KC, ISO 등)의 인증서, peer-reviewed 논문의 독립 검증
결과, 대학·정부출연연구소의 공동 검증 보고서.

**무엇을 인용할지**: 시험기관/인증기관의 이름과 시험 항목, 발급일 또는 시험일,
결과 수치. 회사 자체 내부 테스트 결과만 있고 외부 기관 이름이 없으면 이 항목의
근거로 쓰지 마라 (원칙이 명시적으로 불인정한다).

## A3 — 실환경 가동 (`A3_field_operation_hours`)

**판정 기준 (원칙 원문)**: 실환경 누적 가동 1,000시간 이상

**아키타입별 치환**:

| 아키타입 | 대체 기준 |
|---|---|
| `deep_tech` | Pilot plant 가동 + TRL 6 이상 |
| `materials` | Pilot run 누적 검증. 시간 기준 대신 배치 수와 수율 재현성으로 본다 |
| `industrial_hardware` | (원문 그대로) |
| `energy_infra` | 실증 사이트 가동 + 성능보증(PPA 또는 성능계약) 체결 |
| `recycling` | 파일럿 플랜트 누적 처리량과 recovery rate 재현성 |
| `software_ai_robotics` | 프로덕션 배포 후 운영 기간과 uptime. 가동시간 기준을 적용하지 않는다 |

**어디서 찾는지**: 실증 사업 공고·보고서(정부 R&D 과제 결과보고서 포함), 현장
설치 실적을 알리는 보도자료, 회사 기술 소개서의 "누적 가동 시간" 또는 "TRL"
서술, SaaS/로보틱스 계열은 서비스 가동 개시일과 SLA/uptime 공개 자료.

**무엇을 인용할지**: 가동 시간·TRL 단계·배치 수·uptime 등 정량값과, 그 값이
측정된 기간·현장의 수. "장기간 안정적으로 운영 중"처럼 수치가 없는 서술은
`extracted_value`를 만들 수 없으므로 `UNVERIFIABLE`에 가깝다.
